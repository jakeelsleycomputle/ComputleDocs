{% hint style="info" %}
**Computle Client installs:**

* Computle Client, which provides Entra ID authentication.&#x20;
* WireGuard, to facilitate a point-to-point tunnel.
* Mechdyne TGX, enabling 5k display support.&#x20;
* NICE DCV, enabling 4k display support.&#x20;
* Microsoft C++ Redistributable.
{% endhint %}

{% hint style="info" %}
**System requirements:**

* Windows 10/11 or MacOS 12+ ARM.
* 850MB of available storage.
* Internet access.&#x20;

***

* **For 1080p support:** A 4 core CPU with 5Mbps bandwidth.&#x20;
* **For dual 1080p support:** A 4 core CPU with UDH graphics with 15Mbps bandwidth.&#x20;
* **For dual 4k support and dual 5k support:** An eight core GPU with Iris XE graphics with 50Mbps bandwidth.
{% endhint %}

{% hint style="info" %}
**Silent Installation:**

To install silently, run: _ComputleClientV3\_Setup\_3.0.7.3.exe /S._ The installation will take around 15 minutes.&#x20;
{% endhint %}

{% hint style="info" %}
**Documentation:**&#x20;

View documentation for Computle Client [here](../computle-client/computle-client-v3-release-candidate/computle-client-entra-id.md).
{% endhint %}

{% hint style="info" %}
**Mac (Intel):**&#x20;

Computle Client for Mac (Intel) can be downloaded [here](https://softwaredownloads.oncomputle.com/ComputleClient-3.0.7-Intel.pkg).
{% endhint %}
